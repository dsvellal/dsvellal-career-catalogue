Instructions:

- This question paper has to be answered within 180 mins.
- Each problem statement translates to a java program that the student has to code
- Each java program should have a main() method which when executed, should run the program.
- Any number of questions can be attempted and the criteria of correction has been quoted earlier
- The student should provide a complete working program for each problem statement
- Criteria for judging the program: The program shall be analyzed for correctness of implementation, standard coding practices, algorithm implemented, optimizations used, readability of the program, comments etc.

- There are no negative markings for attempting a program.

1. Assume you have a method isSubstring which checks if one word is a substring of another. Given two strings, root-word and input-word, write code to check if input-word is a rotation of root-word using only one call to isSubstring.


Example:


Root word: HelloWorld


Input word:  WorldHello


Output - True


Input word: orldHelloW


Output - True


Input word: HelloWorld


Output - True


Input word: lloWordHe


Output - False


2. Implement an algorithm to determine if a string has all unique characters. Note: You can not use additional data structures.


Example:


Input string: Hello


Output: False


Input string: Admire


Output: True


Input: Wow


Output: False
