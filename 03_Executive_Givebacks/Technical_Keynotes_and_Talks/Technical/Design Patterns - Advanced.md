## Slide 11: Adapter Pattern

- This pattern is used when you want to translate one interface of a class into another interface.
- It makes sense that these 2 interfaces are compatible otherwise the pattern may not make sense.
- Very useful when migrating old code base into a new model

## Slide 16: Observer Pattern

- Observer pattern is useful when you have one publisher who pushes the changes, and multiple observers who receive changes.
- Few examples are:
- Stock price watchers
- Social media updates
- RSS readers etc.
