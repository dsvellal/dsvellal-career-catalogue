## Slide 6: Coding Dojo: Requirement

- String Calculator
- Create a simple String calculator  (class) with a method int Add(string numbers)
- The method can take 0, 1 or 2 numbers,
- It will return their sum
- for an empty string it will return 0
- for example “” or “1” or “1,2”
- Start with the simplest test case of an empty string and move to 1 and two numbers
- Remember to solve things as simply as possible so that you force yourself to write tests you did not think about
- Remember to refactor after each passing test

## Slide 9: Coding Dojo: More Requirement

- Now change the Add method to handle an unknown numbers  of arguments (Numbers inside string)
- E.g. “1,2,3” should return 6
- Allow the Add method to handle new lines between numbers (instead of commas).
- The following input is ok:  “1\n2,3”  (will equal 6)
- The following input is NOT ok:  “1,\n” (not need to prove it - just clarifying)
