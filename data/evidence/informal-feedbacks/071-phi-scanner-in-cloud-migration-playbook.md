Section: Static Code Analysis (Continuous Integration)

Listed tools:
- GitHub Copilot: GitHub Copilot is an AI-powered coding assistant that helps developers by suggesting code and auto-completing lines or blocks based on the context of the project. It integrates directly into IDEs like Visual Studio Code, enhancing coding efficiency and reducing development time.

- BlackDuck: It is a Software Composition Analysis (SCA) tool which helps in identifying open-source components within codebases, along with their licensing information and any known security vulnerabilities. And it specializes in creating Software Bills of Materials (SBOMs).

- Dependabot: GitHub Dependabot is an automated tool integrated into GitHub that helps keep project dependencies up to date. It automatically scans for outdated or vulnerable dependencies in your codebase and creates pull requests (PRs) with suggested updates.

- MegaLinter: It is an open-source tool that integrates multiple linters for various programming languages, tools and other quality checks. It helps developers to analyze their source code to uncover potential issues, like coding errors, stylistic inconsistencies, bugs, violations of coding standards, and potential security vulnerabilities. Includes Checkov (Policy as code).

- SonarQube: Focuses on continuous code quality, security, and supports a wide range of languages and integrations. SonarQube's Quality Gates are a set of predefined conditions that must be met to ensure that the code is of high quality. These conditions include metrics such as code coverage, code duplication, and technical debt.

- Fortify SCA: It is a comprehensive static analysis for security vulnerabilities. All new projects should adopt GitHub Advanced Security (GHAS), while Fortify will continue to support legacy projects.

- GitHub Advanced Security: Provides highly curated detection and remediation capabilities crafted by some of the world's best security engineers to ensure your code, secrets, and software supply chain are as secure as possible. It has a distinct advantage due to its seamless integration with the GitHub platform. This makes it a user-friendly choice for projects who are already using GitHub ecosystem.

- Protected Health Information(PHI)-Scanner: An inhouse tool for scanning the repositories for the presence of potential PHI Vulnerability.

- Mutation Testing: Assess the effectiveness of your unit tests by introducing small changes (mutations) to the source code and observing if the tests can detect them.

- CodeScene: It goes beyond traditional code quality metrics by incorporating insights into team behavior and historical code health. It is an intelligent tool that helps developers manage technical debt and improve the maintainability of their codebase.

GitHub Actions are available for all those tools.
