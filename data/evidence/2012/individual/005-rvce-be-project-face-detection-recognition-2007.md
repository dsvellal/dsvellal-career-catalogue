## Project Summary

### Title
"Face Detection and Recognition"

### Synopsis
A computer-driven application for automatically identifying a person from a digital image by comparing selected facial features in a live image against a facial database.

> "The subject of face recognition is as old as computer vision and both because of the practical importance of the topic and theoretical interest from cognitive science."

### Technical Approach
- **Detection:** Skin-color segmentation, golden ratio analysis, histogram-based region detection
- **Recognition:** Principal Component Analysis (PCA) / Eigenface algorithm
- **Preprocessing:** Grayscale conversion, histogram equalization, low pass filtering, noise reduction, resize
- **Implementation languages:** MATLAB (core algorithms) + Java (UI/integration)

### Modules (15 total)
1. Face Detection — skin color + golden ratio
2. Face Histogram — region analysis
3. ConvertToHSV — color space conversion
4. Calculate_Skin — skin detection
5. Region — connected component analysis
6. Goldenratio — facial proportion validation
7. Pre-process — image preparation pipeline
8. Gray Scale Conversion
9. Histogram Equalization
10. Low Pass Filter
11. Resize
12. Face Recognition — eigenface matching
13. Training — database enrollment
14. PCA — Principal Component Analysis (dimensionality reduction)
15. Classification — nearest-neighbor matching
