## Report Summary

### Purpose
Guide leaders and practitioners in prioritizing efforts to reach software excellence. Based on data from 138 projects assessed through the Software Craftsmanship Program in 2023.

### Executive Summary
> "The Software Craftsmanship Program has helped business to improve software practices and to identify risk in assets. An analysis of software related CAPAs (Corrective and Preventive Action) from 2021 and 2023 correlated low maturity in software practices with higher probability of product fault occurrences."

### Key Findings
1. **Testing:** Only 5.9% of engineers fully versed in testing techniques. 94.1% still do manual testing.
2. **Technical Debt:** 66% of projects have no defined process/backlog. Average payback time >6 months.
3. **DevOps:** 94.2% have CI defined, but only 29.4% have automation to deploy to test environments.
4. **Static Analysis:** 95.6% have static code analysis; 78.7% have dynamic analysis.
5. **Languages:** C/C++, C#, Java, Python, JavaScript dominate (polyglot).
6. **Internal market:** ~50% of teams develop for internal customers.

### 4 Key Recommendations
1. **Confidence Through Code:** Culture of testability, automated feedback, invest in engineer training
2. **Continuous Quality Champions:** Define metrics/thresholds, automate checks, quality as part of coding journey
3. **Shifting Left:** Empower developers, streamline code reviews, automate repetitive patterns
4. **Build for Tomorrow:** Combat software rot, process for technical debt, continuous maintenance culture
