### Reference Pipelines — Monitoring Architecture (from slides)

```
Monitoring triplet: (timestamp, key, value)
- Counters: track occurrences
- Alerts: threshold-based triggers
- Rules: condition evaluation

Alert:Action configurations:
- 1:1 — one alert triggers one action
- 1:many — one alert triggers multiple actions
- many:1 — multiple alerts converge to one action
- many:many — complex multi-alert, multi-action scenarios
```
