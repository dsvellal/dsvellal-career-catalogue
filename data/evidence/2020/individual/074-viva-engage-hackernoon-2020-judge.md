### Winners
1. **Binding in Sense** — A framework to automatically update data between the business logic and the Sense controls in the user interface (Marut, Vinayak, Chethan and Santosh)
2. **Linux self-upgrade using remote IGT repository & self-recovery using snapshots** — Automatically upgrading the Linux system using IGT controlled repository along with automatic system recovery in case of un-stable system (Ritesh, Udayan and Tarun)
3. **Your Own Device Assistant** — On-device assistant, to guide the setup, usage, diagnosis and problem reporting, using NLP and ML for Guided Setup, Smart Search and Customized Shortcuts (Praband)

### People's Choice
- **Create 3D image models that can be printed from medical images** — Generating 3D printable STL model from Dicom images which can be directly printed using any available 3D printer (Kiran, Aswin, Raghav, Santosh)

### Special Mentions
- **IGT Stack Overflow** — platform to share knowledge & providing solutions (Raja R, Rashmi, Kishor, Nita)
- **Insights** — A centralized application for real-time system monitoring from live hospital data (Praband, Sauraj)
