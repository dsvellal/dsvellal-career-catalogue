Sonarlint – is a VSCode IDE supported linting extension that’ll help in writing quality code by dynamically running code-quality programming rules (supports both python & JS) as and when we type! This is especially helpful in not incurring known errors. Do consider incorporating this into VSCode.



The method to do so is as follows:

1. In VSCode, click on the wheel (settings) – and search for “Extensions”

2. In the Extensions section, search for “Sonarlint” – you’ll get the extension

3. Click on “Install” and wait for the installation to be successful.

4. Restart IDE.
