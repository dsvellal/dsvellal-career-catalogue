## Context

Sundaresan Jagadeesan posted in the SW_CoE Yammer group announcing parallel hands-on Clean Code workshops running across two rooms on September 25-26, 2019 in PIC and MFAR buildings. Datta (Vellal, Dattatreya) is directly CC'd as an organizer/facilitator. The workshops covered five parallel themes: Duplicate Code identification and removal, Mutation Testing, Code live sessions, Clean Tests, and BDD. Multiple participants posted positive feedback in the thread, specifically crediting the SWCoE team for the sessions. The post was seen by 215 people. The thread also includes photos of the workshop rooms showing active participation.
