## Context
Datta conceived, developed, and led a company-wide initiative to detect and reduce code duplication using JSCPD (JavaScript Copy Paste Detector). Starting with hands-on workshops in September 2019, this grew into a cross-BU program that produced data directly presented to the CTO and PLP leadership.

## Datta's Role & Title
- **Competency Specialist – Software Excellence, Software Center of Excellence**
- Sole architect and driver of this initiative

## Key Contributions Evidenced

### 1. Conceived & Built the Program
Datta designed the entire approach:
- Introduced JSCPD tool to Philips
- Created installation guides and usage documentation
- Designed hands-on workshop curriculum
- Built reporting templates for before/after comparison
- Established metrics tracking

### 2. Delivered Multiple Workshops (Sept-Nov 2019)
- Ran workshops for teams across multiple BUs (EOI, MR, RadOnc, HSDP, IDM, IGT)
- Yammer praise: *"Had a wonderful hands on session on Code duplication identification using JSCPD npm tool for the entire EOI BLR team"*
- 225+ attendees at the Sep'19 SWCoE technical sharing session alone
- Remote sessions for globally distributed teams

### 3. Produced Data for CTO-Level Reporting
From Datta's email to leadership (2019-10-12):
> "I have compiled the following data for the CTO extended call, for this Tuesday. This data consists of the JSCPD workshops and individual sessions we have been running so far with developers et al. since Sept 9th 2019."

Maintained:

- Before/after reports for all analyzed source code
- Quantified results (e.g., "20% Code Duplications in UDM Common Apps")

### 4. Leadership Endorsement
