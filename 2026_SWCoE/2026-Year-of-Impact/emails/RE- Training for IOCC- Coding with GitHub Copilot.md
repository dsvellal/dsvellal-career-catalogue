For the benefit of folks who couldn't join today, here's a list of key prompts we used in VS Code to bring value to our day-day development activities.

1. The No Assumptions prompt

This one is fantastic for complex planning. It forces the tool to act as a structured guide rather than just spitting out a rushed, assumptive answer.

Prompt Template:

Treat my prompt as an "intent". DO NOT assume anything. DO NOT take any decisions. Ask me questions. One question at a time. Give me multiple choices for each question, and your recommended answer. Present explicitly the reasoning for each choice. Capture all of my decisions in a decisions.md file. In the future, if the same decision has to be taken, refer to the decisions.md file; if you do not find an answer, then ask me questions.

2. Multi-Dimensional Code Review

When you want a thorough critique instead of a generic 'looks good,' use this layout. It forces the model to evaluate your work across specific, vital engineering pillars.

Prompt Template:

Review my code from the following points of view (spawn sub-agents if needed):

1.                  Maintainability

2.                  Extension

3.                  Security

4.                  Readability

5.                  Performance

Tell me, for each of these points of view, what am I doing well, and what should I improve?

3. Persona-Driven Code Review

Sometimes you need a highly specific lens. Swap out the bracketed variables for things like "a ruthless security auditor" or "a senior React developer obsessed with accessibility."

Prompt Template:

Review my code as a who is well versed in . What am I doing well, and what should I improve?

4. PR Thread Summarization

Pull requests get incredibly noisy. This prompt is a lifesaver for catching up on long review threads without accidentally triggering the tool to start writing fixes you don't need yet.

Prompt Template:

Open this PR, and tell me what all the unresolved conversations are in the PR:

DO NOT fix anything. I want you to list the unresolved conversations, and the intent of the comments given in each of the unresolved conversations. Do a deep dive of the code if needed to get the necessary context.

Here are three more bonus prompts for you to explore, to keep the curiosity levels high!

1. The Socratic Debugger

Sometimes you do not want an AI to just hallucinate a fix that might break three other things. You just need a sounding board to help you untangle your own thoughts.

Prompt Template:

I am dealing with a bug in the following code regarding . DO NOT rewrite the code or give me the direct solution right away. Instead, act as a senior engineer doing a pairing session. Ask me probing questions about my logic, point out potential edge cases I might have overlooked, and guide me to find the root cause myself.

2. The Bulletproof Refactor

It's that universal feeling of staring at a sprawling, 500-line legacy function, terrified that tweaking a single variable will bring the whole system crashing down. You need the code to be cleaner, but it must remain strictly backward compatible.

Prompt Template:

Refactor the provided code block to improve cyclomatic complexity and overall readability. You must adhere to these strict constraints:

1.                  The public API and method signatures cannot change.

2.                  Do not introduce any external libraries or new dependencies.

3.                  Ensure the time complexity does not degrade.

After providing the refactored code, explain exactly what structural changes you made and why.

3. The Edge-Case Hunter (TDD Kickstart)

Writing tests is a chore. Even worse, humans are naturally biased toward writing tests for the 'happy path' and missing the weird, one-in-a-million inputs that actually crash production.

Prompt Template:

I am about to write a function that does . Before I write the implementation, act as a destructive QA tester. Generate a bulleted list of the most obscure, nasty edge cases and invalid inputs this function might encounter in the wild. Then, draft the skeleton for a comprehensive test suite using that covers these exact scenarios.
