Folksonomies
A collaborative but unsophisticated way in which information is
being categorized on the web. Instead of using a centralized form
of classification, users are encouraged to assign freely chosen
keywords (called tags) to pieces of information or data, a process
known as tagging.

Provide an unrestricted way of building a vocabulary
–Lightweight, quick and easy
–Little constraint on users (thus popular)
–Produce flat collections of keywords

RSS
• Stands for Really Simple Syndication
• Lightweight standard
• Allows publication of content feeds
– Linking to resources
– Notifications of page changes.
– Dynamic linking
– Publish / Subscribe

• RSS feeds describe items
– Title, Description, Link, Publication date etc.

• Applicable on: Browsers, Desktops, Mobile Devices
etc.
• Alternatives exists, e.g. Atom, TPEG (Transport Protocol
Experts Group)

SaaS – Software as a Service
• Software as a Service (SaaS) is a model of software deployment where
an application is hosted as a service provided to customers across the
Internet
The key characteristics of SaaS software
– Network-based access and management of commercial software
– Activities are managed from central locations
– Enables customers to access applications remotely via the Web
– Application delivery that typically is closer to one-to-many model
– Centralized feature updating
– SaaS is often used in a larger network of communicating software either as part of a mashup or as a plugin to a platform as a service.

Cloud Computing
•

Cloud Computing: A paradigm in which information is permanently stored in servers
on the Internet and cached temporarily on clients that include desktops, entertainment
centers, tablet computers, notebooks, wall computers, handhelds, monitors etc.

Key Characteristics
• Customer capital minimized
• Device and location independence
• Multi-tenancy
• Utilization and efficiency improvements
• On-demand allocation and de-allocation
• Global performance monitoring and consistency
• Reliability via multiple redundant sites
• Scalability
• Security improvements via data centralization
• Sustainability via improved resource utilization
